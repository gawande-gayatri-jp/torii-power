# TORII Power · Demo edition

An interactive demo of TORII Power, a Japan power-market intelligence platform concept:
day-ahead price distributions, nine-area grid, PPA and battery valuation, balancing,
fuels-to-power, a contract exchange and an algorithmic trading desk, all in one page.

**All figures are illustrative sample data from a research prototype.** They are not a live
forecast, a performance claim or investment advice. The page runs entirely in the browser;
anything you enter is kept only in your own browser.

Open `index.html` in any modern browser, or visit the deployed site.
